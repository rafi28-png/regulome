1. WHAT IS REGULOME?
================================================================================
ReguloMe is a next-generation regulatory genomics platform that lets users
interpret, visualize, simulate, and optimize the human non-coding regulatory
genome. It features a cinematic "God-Mode" UI with glassmorphism, neon gradients,
and smooth animations throughout.

================================================================================
2. TECH STACK
================================================================================
FRONTEND:
  • React 18 + TypeScript
  • Vite (build tool & dev server)
  • Framer Motion (animations)
  • Recharts (charts & graphs)
  • React Three Fiber + Three.js (3D genome visualization)
  • Lucide React (icons)
  • TailwindCSS + Custom CSS (styling)
  • React Router DOM (routing)

BACKEND:
  • Python FastAPI
  • SQLite (auth + bookmarks database)
  • Uvicorn (ASGI server)
  • External APIs: Ensembl, ClinVar, GTEx, Open Targets

STATE MANAGEMENT:
  • Custom React Context (AppContext)
  • LocalStorage persistence for mode, persona, user identity, upload state

7. BACKEND API (FastAPI + Python)
================================================================================

SERVER: uvicorn running on http://localhost:8000
DOCS: http://localhost:8000/docs (Swagger UI)

ENDPOINTS:
  POST /api/v1/auth/signup     — Create account (name, email, password)
  POST /api/v1/auth/login      — Login (returns JWT token)
  GET  /api/v1/health          — Server health check
  GET  /api/v1/bookmarks       — List saved bookmarks
  POST /api/v1/bookmarks       — Create bookmark
  DEL  /api/v1/bookmarks/:id   — Delete bookmark
  GET  /api/v1/genomics/gene/:name    — Ensembl gene lookup
  GET  /api/v1/genomics/variant/:rsid — ClinVar variant lookup
  GET  /api/v1/genomics/expression/:gene — GTEx expression data

DATABASE: SQLite (auto-created)
  • users table: id, name, email, password_hash, created_at
  • bookmarks table: id, user_id, variant_id, label, created_at

SERVICES (14 files):

  • disease_service.py (10KB) — Disease pathway computations
  • auth_service.py — JWT token generation & password hashing

9. STATE MANAGEMENT (AppContext)
================================================================================

Global state stored in React Context + LocalStorage:

  mode: 'demo' | 'real'              — Current operating mode
  currentPersona: DemoPersona | null  — Selected demo profile
  isAuthenticated: boolean            — Login status
  userName: string | null             — Logged-in user's name
  userEmail: string | null            — Logged-in user's email
  hasUploadedData: boolean            — Data Studio completion flag
  sidebarOpen: boolean                — Sidebar visibility
  sidebarCollapsed: boolean           — Sidebar compact mode

LocalStorage Keys:
  regulome:mode                       — Persisted mode selection
  regulome:persona                    — Persisted persona JSON
  regulome:auth-token                 — JWT authentication token
  regulome:is-authenticated           — Auth flag
  regulome:user-name                  — User display name
  regulome:user-email                 — User email
  regulome:has-uploaded-data          — Upload completion flag
