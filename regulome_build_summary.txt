1. PLATFORM OVERVIEW
--------------------------------------------------------------------------------
ReguloMe is a Next-Generation Regulatory Genomics Platform designed to interpret,
visualize, simulate, and optimize the human non-coding regulatory genome. 
It merges high-end, cinematic UI/UX ("God-Mode" design) with complex scientific
data visualization.

2. ARCHITECTURE & TECH STACK
--------------------------------------------------------------------------------
• Frontend: React 18, TypeScript, Vite
• Styling: TailwindCSS, raw CSS modules (Glassmorphism, Neon gradients)
• Animations: Framer Motion (staggered entries, floating orbs, page transitions)
• Data Visualization: Recharts (Charts), D3.js (Networks), React-Three-Fiber (3D)
• Icons: Lucide React
• Backend Interface: FastAPI (Python) with SQLite for auth and persistent bookmarks.
• State Management: Custom AppContext with LocalStorage persistence.

3. DESIGN SYSTEM ("GOD-MODE")
--------------------------------------------------------------------------------
The entire platform was overhauled to look cinematic, premium, and futuristic:
• Deep dark mode backgrounds (#0a0e1a)
• Glassmorphism panels (backdrop-blur, translucent borders)
• Dynamic lighting (floating gradient orbs tracking scroll/position)
• Custom typography and spacing to match high-end enterprise software.
• Custom components: Button (with 'glow' effects), GlassCard, StatCard, etc.

4. CORE MODULES & PAGES (14 Pages)

5. DEMO MODE vs. REAL MODE WORKFLOW
--------------------------------------------------------------------------------
We architected a distinct dual-mode system to serve both casual explorers and 
hardcore researchers:

[🎭 DEMO MODE ]
• Aesthetic: Teal/Blue neon accents.
• Data: Uses predefined "Personas" (e.g., Inflammatory Immune-Skewed, 
  Metabolic Risk, Centenarian).
• Experience: Instant access to fully populated dashboards to showcase the 
  platform's capabilities without needing actual genomic files.

[🧬 REAL MODE ]
• Aesthetic: Deep Purple neon accents (visually distinct from Demo).
• Authentication: Requires account creation or login (backed by SQLite).
• Data Studio (The Pipeline): Instead of dropping users into an empty dashboard, 
  Real Mode strictly requires users to visit the "Data Studio".
• Cinematic File Upload: Users upload their VCF/23andMe file. The system runs 
  a 10-second cinematic terminal sequence simulating the backend pipeline 
  (parsing VCF, mapping to hg38, calling ClinVar/Ensembl APIs, calculating age).
• Personalized Dashboard: Once the pipeline finishes, the dashboard unlocks, 
  greeting the user by their authenticated name and displaying feature strips 
  exclusive to Real Mode (Persistent Database, Live APIs).
