# ReguloMe: Regulatory Genomics Platform

ReguloMe is a premium, rigorous, and visually exceptional platform for regulatory genomics analysis.

## Tech Stack
- **Frontend framework:** React + TypeScript + Vite
- **Styling:** Tailwind CSS + custom design tokens
- **Backend:** FastAPI (Python)
- **Icons:** Lucide React
- **Theme:** Cinematic visual design with sophisticated dark mode styling.

## Running the Project

**Frontend:**
```bash
npm install
npm run dev
```

**Backend (Python/FastAPI):**
```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```
